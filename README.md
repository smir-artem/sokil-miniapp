# sokil-miniapp

Сторінки Telegram Mini App бота СФК «Сокіл» (GitHub Pages).

- `attendance.html` — відмітка відвідування тренером.

Тут немає даних і секретів: список дітей бот передає в адресі сторінки (параметр `?d=`).
Джерело — `miniapp/attendance.html` у приватному репозиторії бота; після змін копію оновлювати тут.
